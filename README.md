Masters-Thesis-final
Masters-Thesis-final is a master's thesis project focused on evaluating whether machine learning models can predict NBA betting outcomes more accurately than sportsbook lines. The project will compare model predictions against market benchmarks using historical NBA data, betting lines, and game outcomes.

Research Question
Can machine learning models produce NBA betting outcome predictions that outperform sportsbook lines under consistent evaluation criteria?

Planned Phases
Project setup and documentation.
Data source research and collection planning.
Historical NBA and betting line data preparation.
Exploratory data analysis and baseline evaluation.
Machine learning model development and validation.
Performance comparison against sportsbook lines.
Thesis writing, interpretation, and final presentation.
Planned Tech Stack
Python for data processing, analysis, and modeling.
Jupyter notebooks for exploratory analysis and experimentation.
Pandas, NumPy, and scikit-learn for data preparation and machine learning.
Matplotlib or Seaborn for visual analysis.
Git and GitHub for version control.
Folder Structure
docs/ - thesis notes, references, and planning documents.
notebooks/ - exploratory analysis and modeling notebooks.
scripts/ - reusable data processing and analysis scripts.
models/ - saved model artifacts and experiment outputs.
data/ - local datasets excluded from version control where appropriate.
