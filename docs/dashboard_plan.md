# **Dashboard Plan**

## **First Dashboard Page Goals**

- Present a clear overview of NBA games, betting lines, and model-ready fields.
- Support early thesis exploration without implying final model performance.
- Provide a simple structure for comparing sportsbook lines with future predictions.
- Keep the first version focused on data understanding, not automated betting decisions.

## **Mock NBA Game Fields**

- Game date
- Home team
- Away team
- Home score
- Away score
- Point spread
- Moneyline odds
- Total points line
- Actual winner
- Spread result
- Over/under result

## **Future Prediction Metrics**

- Prediction accuracy
- Precision and recall
- Log loss
- Mean absolute error for spread or total predictions
- Return on investment simulation
- Model performance versus sportsbook baseline

## **Possible APIs for Later Use**

- NBA API for game and team data
- Sportsbook odds API for betting lines
- Historical odds data providers
- Basketball Reference or similar statistical sources
- Kaggle datasets for exploratory historical analysis

## **Long-Term Research Direction**

- Build a reproducible dataset combining NBA outcomes, team statistics, and sportsbook lines.
- Develop baseline models before testing more advanced machine learning approaches.
- Evaluate whether model predictions offer measurable improvement over market lines.
- Analyze limitations, market efficiency, data bias, and practical relevance for sports analytics research.
